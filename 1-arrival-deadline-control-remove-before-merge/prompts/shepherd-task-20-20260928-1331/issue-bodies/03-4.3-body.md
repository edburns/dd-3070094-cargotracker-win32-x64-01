## Resolved decisions and research findings

- Keep the web boundary layered: the backing bean uses `BookingServiceFacade` and `CargoRoute`; it must not access `Cargo`, `TrackingId`, `RouteSpecification`, or a repository.
- Keep date conversion in the view-scoped editor. Load `CargoRoute` through `loadCargoForRouting(trackingId)` and parse its date-only representation with a per-load `new SimpleDateFormat("MM/dd/yyyy")`. The plan records that the full formatted deadline begins with `MM/dd/yyyy`; parsing the DTO's displayed date representation yields that same calendar date.
- Do not add a shared mutable `SimpleDateFormat` or broaden `CargoRoute` with a new `Date` property.
- Surface malformed DTO dates as a clear application/view error. Never swallow the exception, print a stack trace, or silently submit `null`.
- The editor is a serializable CDI `@Named @ViewScoped` bean. Dynamic-dialog launching remains a separate session-scoped JSF managed bean for task 4.
- Require a non-null selected date, but add no minimum, future, old-deadline, or itinerary-date rule.
- A successful submission delegates to the facade and closes with `"DONE"`. A facade failure must propagate and must not close the dialog.
- Research established that tests should be container-free where practical and use hand-written fakes; no mocking dependency or Arquillian modernization is warranted.

## Implement

Create:

- `src/main/java/org/eclipse/cargotracker/interfaces/booking/web/ChangeArrivalDeadlineDate.java`

Required shape:

```java
@Named
@ViewScoped
public class ChangeArrivalDeadlineDate implements Serializable {
    private static final long serialVersionUID = 1L;

    private String trackingId;
    private CargoRoute cargo;
    private Date arrivalDeadlineDate;

    @Inject
    private BookingServiceFacade bookingServiceFacade;
}
```

Provide:

- `getTrackingId()` and `setTrackingId(String)`;
- `getCargo()`;
- `getArrivalDeadlineDate()` and `setArrivalDeadlineDate(Date)`;
- `load()`;
- `changeArrivalDeadline()`.

`load()` must call `bookingServiceFacade.loadCargoForRouting(trackingId)`, retain the returned `CargoRoute`, parse the DTO's `MM/dd/yyyy` date into `arrivalDeadlineDate`, and explicitly surface parsing failures in the repository's established JSF error style.

`changeArrivalDeadline()` must reject a null date, call `bookingServiceFacade.changeDeadline(trackingId, arrivalDeadlineDate)`, and only after successful return call:

```java
PrimeFaces.current().dialog().closeDynamic("DONE");
```

Do not add the launcher or XHTML in this task.

## Tests

Add a container-free JUnit test if practical with a hand-written facade fake. Prove:

- `load()` requests the exact tracking ID;
- an `MM/dd/yyyy` DTO date becomes the editable `Date` for the same calendar day;
- submission delegates the exact tracking ID and selected date;
- malformed DTO input surfaces an error rather than becoming `null`;
- a null selected date is rejected;
- a facade exception prevents the close call or otherwise propagates before successful-close behavior.

Do not add a mocking framework solely for these tests. Keep tests compatible with the historical build and dependencies.
